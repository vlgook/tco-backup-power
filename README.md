# Калькулятор TCO резервного живлення

Порівнює повну вартість володіння (TCO) семи сценаріїв резервного живлення об'єкта під час відключень:
ДГ, УЗЕ, УЗЕ+ДГ, УЗЕ+PV, УЗЕ+PV+ДГ, УЗЕ+PV+вітер, УЗЕ+PV+вітер+ДГ.

**Відкрити:** https://vlgook.github.io/tco-backup-power/

- Один HTML-файл, працює у браузері, дані зберігаються локально.
- Графік відключень: 6 чергувань «є/немає світла» на добу, кілька типів діб.
- Схід і захід сонця за точкою на карті, прогноз генерації PV за даними Open-Meteo (ERA5, 2015–2024).
- Проєкт можна зберегти у файл JSON і відкрити пізніше.

Розрахунок оціночний, для попереднього порівняння варіантів. Він не замінює проєкт і техніко-економічне обґрунтування.

Розробка: Володимир Гук, ELKO Ukraine · energy@elko.ua
