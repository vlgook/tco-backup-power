# Калькулятор TCO резервного живлення · версія 6.1

Порівнює повну вартість володіння (TCO) семи сценаріїв резервного живлення об'єкта під час відключень за 10–20 років:
ДГ, УЗЕ, УЗЕ + ДГ, УЗЕ + PV, УЗЕ + PV + ДГ, УЗЕ + PV + вітер, УЗЕ + PV + вітер + ДГ.

**Відкрити:** https://vlgook.github.io/tco-backup-power/

Розроблено для партнерів і клієнтів ELKO Ukraine, відділ проєктної дистрибуції, група енергетичних рішень.

## Що рахує

- **TCO по роках** для кожного сценарію: обладнання, монтаж, заміни, обслуговування, пальне, електроенергія з мережі та вартість простою.
- **Окупність і ROI** відносно обраної бази (ДГ або «Без резерву»), на додаткові та на всі інвестиції.
- **NPV:** за ставки дисконтування понад 0% з'являється колонка «TCO, NPV», а окупність і ROI рахуються з дисконтованих сум.
- **Простій** за рік і для одного найгіршого відключення: найдовшого, у найважчому сезоні, з батареєю наприкінці строку служби.
- **Багатодобовий блекаут** з урахуванням запасу пального на об'єкті й інтервалу його підвезення.
- **Старіння і заміна АКБ**, дозаряд від мережі, логіка гібриду УЗЕ + ДГ (запуск ДГ при 20%, зупинка при 90% заряду).

## Дані для розрахунку

- **Вхідні дані** зібрано в чотири блоки: «Об'єкт», «Обладнання», «Ускладнення», «Економіка і різне». З кожного блоку можна перейти до відповідного розділу методики.
- **Графік відключень** задається частками або графіком доби: 6 чергувань «є / немає світла», кілька типів діб.
- **Локація на карті** визначає схід і захід сонця в кожному сезоні.
- **Генерація PV** береться з погодинного опромінення Open-Meteo (ERA5, 2015–2024) для точки й нахилу панелей.
- **Генерація вітру** надходить з [VAWT Advisor](https://vlgook.github.io/vawt-advisor/). Звідти ж приходить крива турбіни, за якою з погодинного вітру ERA5 розраховується гарантована частка вітру в найгірше відключення.
- **Перевірки вводу** ловлять неможливі й неправдоподібні значення. Поки є помилки, результат не показується.

## Тестовий приклад

28-поверховий будинок на Осокорках у Києві: 260 кВт·год на добу, пік 35 кВт, база «Без резерву», ставка дисконтування 15%. Приклад відкривається при першому запуску, а також через «Новий проєкт → Тестовий приклад». Лідер за 10 років – «УЗЕ + PV», TCO 8 610 486 грн.

## Як зберігаються дані

Застосунок складається з одного HTML-файлу і працює в браузері. Сервера немає, тож дані кожного користувача лишаються в його браузері. Браузер пам'ятає останній проєкт, а кілька об'єктів ведуть через файли JSON («Зберегти проєкт» / «Відкрити проєкт»). Зміни того самого проєкту в іншій вкладці застосунок помічає і пропонує обрати версію. Результат VAWT Advisor, відкритого кнопкою з проєкту, повертається саме в цей проєкт. Файли, збережені попередніми версіями, відкриваються з поясненням, які поля додано.

## Автотест

`tests/ui_test.py` проганяє 78 перевірок у headless Chromium:
- структуру вводу, перерахунок, збереження й відкриття проєкту;
- перевірки з переходом до поля, друк, новий проєкт;
- горизонт 20 років, дисконтування, частку вітру з погодинних даних;
- межі правдоподібності, одиниці в полях, зіпсовані файли, клавіатуру й мобільну ширину 380 px.

Окремо тест звіряє еталон тестового прикладу.

```
pip install playwright && python -m playwright install chromium
python tests/ui_test.py
```
