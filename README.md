# Калькулятор TCO резервного живлення

Порівнює повну вартість володіння (TCO) семи сценаріїв резервного живлення об'єкта під час відключень:
ДГ, УЗЕ, УЗЕ+ДГ, УЗЕ+PV, УЗЕ+PV+ДГ, УЗЕ+PV+вітер, УЗЕ+PV+вітер+ДГ.

**Відкрити:** https://vlgook.github.io/tco-backup-power/

- Один HTML-файл, працює у браузері, дані зберігаються локально.
- Графік відключень: 6 чергувань «є/немає світла» на добу, кілька типів діб.
- Схід і захід сонця за точкою на карті, прогноз генерації PV за даними Open-Meteo (ERA5, 2015–2024).
- Проєкт можна зберегти у файл JSON і відкрити пізніше.
- Дані кожного користувача лишаються в його браузері, сервера немає. Браузер пам’ятає останній проєкт; кілька об’єктів ведуть через файли JSON, «Новий проєкт» починає порожній проєкт або тестовий приклад. Горизонт розрахунку 10–20 років, за бажанням зі ставкою дисконтування. Зміни того самого проєкту в іншій вкладці застосунок помічає і пропонує обрати версію. Результат VAWT Advisor, відкритого кнопкою з проєкту, повертається саме в цей проєкт.

Розрахунок оціночний, для попереднього порівняння варіантів. Він не замінює проєкт і техніко-економічне обґрунтування.

Розробка: Володимир Гук, ELKO Ukraine · energy@elko.ua

## Автотест

`tests/ui_test.py` проганяє 50 перевірок у headless Chromium: структуру вводу, перерахунок, збереження й відкриття проєкту, перевірки з переходом до поля, друк, новий проєкт (порожній і тестовий приклад), горизонт 20 років, дисконтування, файл попередньої версії і мобільну ширину 380 px. Еталон тестового прикладу (10 років, ставка 0%): лідер «УЗЕ + PV + вітер», TCO 13 653 669 грн.

```
pip install playwright && python -m playwright install chromium
python tests/ui_test.py
```
